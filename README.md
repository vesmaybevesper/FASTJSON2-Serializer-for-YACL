<p>Am I Up To Date is a lightweight mod designed to be included in modpacks to check the local version against the most recent version and notify the user of an update.</p>

---------------------------------------------------------------------------------------------------
## Usage

Setup _Am I Up To Date?_ for your modpack:

1. Click the "More Options" button on your modpack page
2. Select "Copy ID"
3. Paste what you've copied into the "Modpack ID" text box
6. Save!

**Example (for the "Modern Hypixel Skyblock" modpack):**

**Modpack ID: B9GZBYa6**
